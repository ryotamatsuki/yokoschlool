# NEON RIFT / ネオンリフト

浮遊都市の暴走機械を止める、オリジナルの横スクロール2Dアクション。

## 遊び方

- PC: A/D または左右キーで移動、Space/Wで二段ジャンプ、Shift/Xで無敵ダッシュ。
- スマホ: 左右ボタン、JUMP、DASH。縦画面・横画面対応。横画面推奨。
- 自動射撃・自動照準が標準。チェックを外すとZ/Jで手動射撃。上キーで上向き照準。
- P / Esc / Ⅱで一時停止。タブを離れると自動停止。
- Wアイテムで18秒間の拡散弾・貫通弾、＋でシールド回復。
- 3エリア、各エリアに巨大機。各エリア中央にチェックポイント。
- CASUALはシールド8・遅い敵弾、STANDARDはシールド5。
- 効果音はSOUND ONで有効化。ベストスコアのみ端末内に保存。

## ローカル実行

```sh
python -m http.server 8080
```

http://localhost:8080 を開く。ビルド・外部依存・外部素材・通信APIは不要。

GitHub Settings → Pages → Deploy from a branch → main / (root) → Save。

## オリジナル素材・権利への配慮

コード、図形によるキャラクター・背景・敵・エフェクト、Web Audio合成効果音を本プロジェクト用に新規制作。既存ゲームの画像・音源・ロゴ・キャラクター・固有設定・マップは利用していません。一般的な横スクロール射撃アクションの操作形式を採用しています。既存作品との提携・公認を表示するものではありません。

第三者商標の網羅的なクリアランス調査は未実施。商用展開時にはタイトルを含め別途確認してください。

## 構成

- index.html: 日本語UI
- style.css: タッチ・縦横画面・セーフエリア向けレイアウト
- game.js: 固定時間刻みのゲームロジック、Canvas描画、合成音声
- tests/simulation.cjs: 実コードを使った進行・入力・ダメージの回帰検証

## 対応

現行のCanvas 2D / Pointer Events対応ブラウザを想定。iOSで全画面APIが使えない場合は横向き表示をご利用ください。実機iPhone/Androidでの最終確認は別途必要です。
